{% extends "base_dashboard.html" %} {% comment %} Liste des factures en deux onglets : « Brouillons » et « Factures validées ». L'état est porté par les query params de l'URL (onglet `onglet`, recherche `q`, bornes `date_min`/`date_max` sur la date d'émission, page `page`) — la page est donc partageable et rechargeable. Les liens d'onglets conservent recherche et filtres (`tab_query`) mais repartent en première page ; les liens de pagination conservent tout (`base_query`). Le formulaire fonctionne sans JavaScript (soumission GET classique) ; Alpine n'ajoute qu'un confort : debounce sur la saisie et soumission automatique des filtres au changement. Un brouillon pointe vers son récap éditable ; une facture validée pointe vers son aperçu mis en forme (facture_apercu, lecture seule). L'onglet Validées porte en plus une colonne Statut (badge coloré préparé par la vue : `statut_libelle`/`statut_badge`, « — » si statut absent) — inutile côté Brouillons, où le statut est toujours « brouillon ». La colonne Actions est présente sur les deux onglets (form POST par ligne, confirmation navigateur, hidden `retour` pour revenir sur la liste dans le même état) : suppression côté Brouillons (`facture_delete` — jamais sur les validées, immuables), génération d'un avoir côté Validées (`facture_avoir`, uniquement sur les factures : cellule vide pour un avoir, on ne génère pas d'avoir d'un avoir).
