{% extends "base_dashboard.html" %} {% comment %} Page « Mon abonnement », accessible à un utilisateur rattaché à une entreprise active. Structure : - récapitulatif de tête : le plan souscrit par l'entreprise (GET /abonnements/me croisé avec GET /abonnements/), son tarif, ses limites, son statut, la date de souscription et l'échéance ; - bandeau d'alerte si la dernière souscription connue est expirée, suspendue ou annulée (aucune souscription active) ; - renouvellement : pour un admin d'entreprise sur un plan payant (`date_fin` présente — le critère même du 409 de l'API), bouton « Prolonger d'un mois » (POST avec confirmation vers `abonnement_prolonger`) ; - « Changer de plan » : les autres plans en cartes, chacun avec un bouton « Choisir ce plan » (POST avec confirmation vers `abonnement_changer`), visible uniquement pour les administrateurs de l'entreprise (`is_entreprise_admin`), l'API restant juge de vérité. Moyen de paiement : l'API n'expose à ce jour AUCUNE route de moyen de paiement ni de facturation d'abonnement — le renouvellement est manuel (documenté comme tel au contrat).
